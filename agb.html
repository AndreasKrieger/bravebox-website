2. Leistung

BRAVE Box ist eine Desktop-Software zur Analyse und Optimierung von DJ-Bibliotheken und Playlists (Serato und Rekordbox). Die Software bietet Funktionen wie Camelot Key Matching, BPM-Verknüpfung, Übergangsrouten-Erstellung, einen interaktiven Energiekurven-Designer sowie den Export modifizierter Playlists/Crates. Alle Daten werden lokal auf Ihrem Gerät verarbeitet.
